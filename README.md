# Star Circuit

A robot space-RPG built with **Blender 5.2** (all models, generated by script) and **Godot 4.7** (engine, GDScript).
Pick a robot, walk around small spherical planets, gather resources, level WoW-style professions, craft upgrades,
then take off, fly around the star system and warp between stars.

## Play it (macOS)

1. Download **StarCircuit-macOS.zip** from the [latest release](https://github.com/austinginder/star-circuit/releases/latest) and unzip it.
2. Drag **Star Circuit.app** into Applications (optional).
3. The first launch is blocked because the app isn't notarized with a paid Apple Developer ID. Allow it once with either:
   - **Right-click the app, choose Open, then Open again.** On macOS 15+ you may instead need System Settings, then Privacy & Security,
     then **Open Anyway**.
   - Or in Terminal: `xattr -cr "/Applications/Star Circuit.app"`

After that it opens normally. It runs natively on Apple Silicon and Intel Macs (macOS 11+).

## Run from source (any OS Godot supports)

No compiling needed: Godot runs the project directly.

    git clone https://github.com/austinginder/star-circuit.git
    cd star-circuit
    brew install --cask godot        # or download Godot 4.7 from godotengine.org
    godot --path game                # play
    godot -e --path game             # open in the editor

The generated models and audio are committed, so Blender and Python are only needed to *change* them (see below).

### Build the macOS app yourself

    # one-time: install export templates (Godot editor > Editor > Manage Export Templates > Download)
    godot --headless --path game --export-release "macOS" ../build/StarCircuit-macOS.zip

### Regenerate assets

    ./play.sh --assets     # rebuild every model in Blender + all audio, reimport, then run
    blender --background --factory-startup --python blender/render_icon.py   # app icon

## Controls

| Planet | |
|---|---|
| WASD / mouse | move / look (click to capture mouse), wheel zooms |
| Space | jump; hold in the air for jetpack (uses energy) |
| Shift / Ctrl | sprint (faster stride, dust, camera kick) / descend |
| E (hold) | gather, talk, use |
| Q | scanner pulse: reveals nodes, logs species |
| R | use an Energy Cell |
| Left mouse | fire blaster at the crosshair (1 energy/shot) |
| F | class ability (Phase Dash / Seismic Slam / Deploy Turret / Drain Nova) |
| G | use a Repair Kit |
| T | break orbit and fly to space |

| Space | |
|---|---|
| Mouse | steer |
| W/S, A/D, Space/Ctrl | thrust, strafe, rise/sink |
| Shift | boost (uses energy) |
| E | land on a nearby planet (F docks at its trade hub) |
| Left mouse | pulse cannons; switches to the mining laser when the crosshair is on rock |
| Right mouse | homing missiles (lock onto the pirate nearest the crosshair) |
| Q | scan the belt for asteroid types and contents |
| M | galaxy map: warp to another star (costs a Warp Cell) |

Panels: I/Tab cargo · C fabricator · K professions · J quest log · H manual · Esc pause/save.

## What's in it

- **4 robots**: Vesper (scout), Grit (miner), Cog (engineer) and Halo (siphon). Each has its own model, perks and starting skills.
- **Procedural galaxy**: 48 stars and about 170 planets across 6 biomes (verdant, arid, glacial, volcanic, crystalline, fungal).
  Planets use the same height function on the surface and from orbit.
- **Walkable spherical planets** with spherical gravity, jetpack, a day/night cycle with solar recharge, water/lava, flora and wandering fauna.
- **Professions (1-100)**: Mining, Botany, Siphoning, Engineering, Exploration, Combat. Nodes are gated and colour-coded by skill (red/orange/yellow/green/grey, like WoW).
- **Crafting**: 15 recipes covering components, consumables and permanent robot upgrades.
- **Combat**: hull + optional shield, hitscan blaster, a class ability per robot, and three rogue-drone enemies:
  the melee Scrapper, the ranged Sentinel (dodgeable bolts) and the elite Brute (telegraphed slam).
  Enemies spawn in camps that pull together and leash home, WoW-style, and respawn after two minutes.
  Levels scale with a world's distance from home, and names are colour-coded by difficulty. Kills drop Drone Scrap and Power Cores,
  which feed combat upgrades (Pulse Blaster, Void Lance, Reinforced Hull, Deflector Shield) and Repair Kits.
- **Exploration depth**:
  - Every world has 6–7 points of interest. Circuit Monoliths hold lore; Ancient Ruins have guarded data caches;
    Crashed Pods can be salvaged; Crystal Geodes mark hotspots of the planet's rarest resource. Undiscovered sites
    show a light beacon, scanner pulses mark them on the **compass bar**, and a 16-entry **Codex** of lore lives in the quest log (J).
  - A per-world **survey** (species scanned plus sites found) pays out XP and a Warp Cell when complete.
  - Biome **weather** (rain, snow, sand, ash, spores, crystal glitter) has storm cycles that thicken the fog, raise the wind,
    and on harsh worlds drain energy.
  - Terrain has **craters** and **polar caps**. Sister planets of the system hang in the sky, rendered from their real terrain.
    Ringed worlds show their rings arcing overhead. Spore-style **floating islands** can be reached by jetpack.
- **Space mining**:
  - Every star system has an asteroid belt between two planet orbits, with dense clusters, a haze of small rock, and often a comet
    with a glowing tail. The belt's mix depends on the star: red dwarfs run icy, hot blue stars carry crystal and void rock.
  - Hold left mouse to cut with the mining laser. Big rocks crack into smaller minable fragments, and every break spills ore shards
    that your tractor field pulls in. Ram rocks too fast and you scrape your hull.
  - Rock types are Rocky, Metallic (Mining 15), Icy (10), Crystalline (30), Void-touched (55) and Comet (20). Each uses Mining skill
    and follows the WoW difficulty colours.
  - New resources: Nickel-Iron, Cryo Ice, Stardust and Exotic Matter. They feed new upgrades (Prospector Laser, Tractor Beam,
    Exotic Reactor), a cheaper Warp Cell recipe, belt bounties, and the "Belt Prospector" story quest.
- **Space combat**:
  - Four corrupted pirate craft built in Blender. Raiders make strafing runs and peel away. Gunships hold range and
    lob plasma. Swarm Drones ram and detonate. Marauders are gold elites that circle you with turret volleys and a regenerating shield.
  - Pirates patrol the asteroid belts in wings that aggro together, and ambush waves drop out of warp behind you with a klaxon.
    The home system stays calm until the story introduces them. Danger scales with distance from home, and flagships guard far systems.
  - Your weapons are hitscan pulse cannons and homing missiles with smoke trails. Brackets mark on-screen threats and red arrows point to
    off-screen ones. Kills drop salvage shards (scrap, power cores, exotic matter) plus credits and Combat XP.
  - New upgrades are Twin Pulse Cannons and the Missile Rack, plus the "Pirate Problem" and "Hunt the Marauder" quests and "Pirate Hunt" bounties.
    If your ship is destroyed, an emergency beacon reboots you near the system's first world.
- **Cargo & orbital stations**:
  - Raw resources and components fill a cargo hold: 150 units, +60 for the Miner. Craft Cargo Pods (+100) and Cargo Pods Mk II (+200)
    to carry more. Consumables and fuel don't count. When the hold is full, gathering and shard pickup stop until you sell.
  - Every system has an orbital trade station (a rotating ring near its first world). Press E to dock. Each station wants two goods
    (about 1.7x price) and has two in surplus (cheap to buy), and prices drift daily, so the galaxy map shows known stations' wants to plan
    trade runs. Stations also offer "Sell all cargo", hull repair, energy recharge and a contract board.
  - Station defence turrets shoot pirates in range, and pirates won't fight inside the station's safe zone. If your ship is destroyed,
    a fifth of your raw cargo spills where you went down, so you can fly back for it.
- **Towns & trade**:
  - The Cradle and about 40% of other worlds host a named trade hub, with a pad, buildings, lamps, wandering townsfolk who chat,
    and its own town theme. Towns are safe zones. In orbit, press **F** to dock right at a planet's hub.
  - **General Goods** merchants buy and sell with supply and demand: local goods are cheap, imports fetch more, and each town
    has a specialty it pays extra for. Stock restocks every in-game day.
  - **Profession Trainers** follow WoW ranks: skills cap at 25 until you train Journeyman (50), Expert (75) and Artisan (100).
    Higher ranks are only taught farther from home; Artisan trainers are rare and live at the galaxy's edge.
  - **Bounty Boards** post three daily contracts (deliver goods, cull drones, survey species, salvage sites). You can hold 3 at once
    and turn them in at any board.
  - **Credits** come from selling, contracts, drone kills, landmark caches and story quests.
- **Audio**: 8 looping music tracks and 50 sound effects, all synthesised from code (`audio/`).
  Music follows context: menu, a cozy town theme, one theme per world type (bright, arid, crystal, volcanic), deep-space,
  plus a combat layer that crossfades in while drones are chasing you. Effects cover footsteps, jetpack, gathering loops,
  blaster, hits, explosions, the Brute's warning and slam, abilities, UI, quests, level-ups, takeoff and warp.
  Wind and creature calls are positional. Volume sliders (Master, Music, Effects, Interface, Ambience) are in the pause menu.
- **Character levels (1-30)**, a **23-quest storyline** (combat, trade and training quests included), saved by quest ID so new quests never break old saves from the Archivist, an autosaving **save/load**.

## Audio pipeline

    audio/.venv/bin/python audio/build_music.py [track ...]   # -> game/assets/audio/music/*.ogg
    audio/.venv/bin/python audio/build_sfx.py [name ...]      # -> game/assets/audio/sfx/*.wav
    audio/.venv/bin/python audio/analyze.py out.png files...  # levels, clipping, loop seams, spectrograms

`audio/synth.py` is a small numpy synth: oscillators, FM, filters, envelopes, convolution reverb and delay.
The composer is seeded and deterministic. Setup: `python3 -m venv audio/.venv && audio/.venv/bin/pip install numpy scipy matplotlib`,
plus `brew install vorbis-tools` for `oggenc`.

## Layout

    blender/build_assets.py     every model (robots, NPC, nodes, flora, fauna, props) -> game/assets/models/*.glb
    game/scripts/autoload/      db.gd (all tunable data), galaxy.gd (procgen), game.gd (state, quests, save)
    game/scripts/planet/        planet_gen.gd (terrain), planet_world.gd, resource nodes, critters, NPC
    game/scripts/player/        planet_player.gd (spherical controller), robot_visual.gd (procedural animation)
    game/scripts/space/         star system + flight
    game/scripts/ui/            hud, galaxy map, main menu, ui kit
    game/shaders/               terrain, sky, atmosphere, water, star
    game/scripts/dev/           smoke_test.gd (headless E2E) and screenshots.gd (visual tour)

Dev checks:

    godot --headless --path game res://scenes/dev_smoke.tscn   # gameplay loop, prints [smoke] lines
    godot --path game res://scenes/dev_shots.tscn              # renders a screenshot tour into shots/
    SHOTS=combat godot --path game res://scenes/dev_shots.tscn # combat-only screenshot tour
    godot --headless --path game res://scenes/dev_brute.tscn   # elite Brute chase/slam check
    DIST=6 godot --path game res://scenes/dev_flicker.tscn      # frame-diff flicker detector on a ringed planet
    SHOTS=depth godot --path game res://scenes/dev_shots.tscn  # landmarks / compass / lore / weather tour
    SHOTS=sky godot --path game res://scenes/dev_shots.tscn    # night sky, rings, floating islands
    SHOTS=town godot --path game res://scenes/dev_shots.tscn   # towns, merchant/trainer/board panels, docking
    SHOTS=belt godot --path game res://scenes/dev_shots.tscn   # asteroid belt, scanner, mining laser, shards, comet
    SHOTS=spacefight godot --path game res://scenes/dev_shots.tscn  # pirates, cannons, missiles, threat markers, Marauder
    SHOTS=station godot --path game res://scenes/dev_shots.tscn     # sprint, orbital station, market tabs
    godot --headless --path game res://scenes/dev_sprint.tscn       # walk vs sprint ground speed
    PIRATE=gunship godot --headless --path game res://scenes/dev_pirate.tscn  # one pirate's pursuit/fire behaviour
    godot --path game --write-movie /tmp/tour.avi --fixed-fps 30 res://scenes/dev_audio.tscn  # record a session with audio
